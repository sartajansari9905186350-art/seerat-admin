# SEERAT Admin Web Panel

Static web application for the SEERAT Islamic Social & Reels administrative portal, deployed to GitHub Pages.

## Connected Backend
- **Live API Base URL**: `https://seerat-backend.onrender.com/api/admin`

## Features
- Administrative Authentication & JWT Session Handling
- Moderation & Review Queue for User-Generated Reels and Posts
- Content Management & Categories
- User Profiles & Account Moderation (Verify, Suspend, Reinstate)
- Incident Reports & Moderation Actions
- Staff & Administrator Access Control
- Audit Logs
- System Configuration & Policy Controls
